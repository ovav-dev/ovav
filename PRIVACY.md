# OVAV Privacy

## Data Handling

OVAV operates source-local. No data leaves the repository without explicit user authorization.

## Snapshots

Install **snapshots** contain file state for rollback purposes. Snapshots are stored locally and never transmitted externally.

## Handoff Protocol

Cross-area **handoff** between Platform Engineering and **Research Intelligence** uses sanitized channels. No raw context mixing between profiles.

## Research Intelligence Privacy

Research Intelligence accesses web content through a governed context firewall. All external sources are validated before integration.
