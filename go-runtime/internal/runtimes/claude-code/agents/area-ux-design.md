# Ux Design

**Lead:** elena

## Functions

- Diseño de interfaces: Wireframes, mockups, prototipos interactivos para productos OVAV.
- User research: Entrevistas, tests de usabilidad, análisis de comportamiento.
- Arquitectura de información: Estructura de navegación, flujos de usuario, taxonomías.
- Accesibilidad (a11y): Cumplimiento WCAG, diseño inclusivo, contraste y legibilidad.
- Design system: Componentes, tokens de diseño, guías de estilo para consistencia visual.
- Prototipado rápido: Validación temprana de conceptos con usuarios reales.
- UX writing: Microcopy, mensajes de error, tooltips, onboarding textual.
- Journey mapping: Mapeo de experiencias end-to-end del usuario OVAV.
