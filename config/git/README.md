## Metadata

| Field | Value |
|-------|-------|
| version | 1.0.0 |

## Deploy Targets

- `config/git/gitconfig` → `~/.gitconfig`
- `config/git/gitignore` → `.gitignore` (repo root)

## Features

- OVAV signing (GPG)
- AI+Human commit model (author=agent, committer=human)
- Short aliases
- Auto-color
