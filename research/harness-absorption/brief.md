# Research Brief: pi.dev / pi.agent — Governance Absorption

**Question**: What governance, observability, and external-integration capabilities does pi.dev (pi.agent) have in 2026 for running a system like OVAV SYSTEM?

**Scope**:
- In: governance APIs, observability (logs/events/hooks), extension system, headless/server mode, CLI, token overhead, external integrations
- Out: general LLM capabilities, unrelated agent frameworks

**Assumptions**: Today is 2026-08-06. pi.dev/pi.agent is a real agent platform being evaluated for extensibility and governance suitability.

**Depth**: standard — 3-5 angles, up to 1 follow-up round

## Angles
1. **Core platform & extensions**: What is pi.dev/pi.agent? Extension APIs, governance hooks, MCP/server integrations.
2. **Headless / server-side**: Can it run as a background service, pure governance layer, no UI?
3. **Observability**: Logs, events, webhooks, external monitoring integration.
4. **Token overhead**: What is the cost of its extension/plugin system?
5. **Comparison**: How does it compare to other agent harnesses (LangGraph, AutoGen, CrewAI, etc.) for extensibility.
