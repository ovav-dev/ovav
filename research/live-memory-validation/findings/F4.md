# F4: MiMoCode harness context hooks

## Findings

### [1] MiMoCode headless mode emits structured JSONL events including tool_use with state
- quote: "`mimo run --format json` writes one JSON object per line. Emitted event types: `step_start`, `text`, `reasoning`, `tool_use`, `step_finish`, `error`"
- url: https://mimo.xiaomi.com/mimocode/cli-subcommands (inferred from drive-mimo skill at ~/.local/share/mimocode/builtin_skills/0.1.10/skills/drive-mimo/SKILL.md)
- source_type: primary
- published: unknown
- confidence: high

### [2] MiMoCode `tool_use` event contains tool name, status, and completion state — but no raw output
- quote: "`tool_use` is emitted once per tool part when it reaches `completed` or `error` — the result/output is inside `part.state`; there is no separate result event."
- url: https://mimo.xiaomi.com/mimocode/cli-subcommands (from drive-mimo skill)
- source_type: primary
- published: unknown
- confidence: high

### [3] MiMoCode has NO public hooks/events API for external real-time observation
- quote: "MiMoCode has no documented hooks system, no OpenTelemetry export, and no push-based channel mechanism. Monitoring is limited to parsing the JSONL event stream from `mimo run --format json`." (synthesized from MiMoCode docs — tools, agents, sessions, MCP, and custom-commands pages, none of which mention hooks or observability APIs)
- url: https://mimo.xiaomi.com/mimocode/tools, https://mimo.xiaomi.com/mimocode/agents, https://mimo.xiaomi.com/mimocode/sessions, https://mimo.xiaomi.com/mimocode/mcp-servers
- source_type: primary
- published: unknown
- confidence: high

### [4] MiMoCode context persists via session storage at `$MIMOCODE_HOME/data/` and auto-compaction
- quote: "MiMoCode persists every conversation as a session, retaining its message history and metadata. `mimo export [sessionID]` exports to JSON. Compaction is performed by a hidden Compaction agent that compresses long context."
- url: https://mimo.xiaomi.com/mimocode/sessions
- source_type: primary
- published: unknown
- confidence: high

### [5] MiMoCode `snapshot` config enables filesystem change tracking for undo/revert
- quote: "Enable or disable snapshot tracking. When false, filesystem snapshots are not recorded and undoing or reverting will not undo/redo file changes."
- url: https://mimo.xiaomi.com/mimocode/config.json (schema at https://mimo.xiaomi.com/mimocode/config.json)
- source_type: primary
- published: unknown
- confidence: medium

### [6] Claude Code has comprehensive hooks system for monitoring with PreToolUse/PostToolUse events
- quote: "Events fire at specific points: `SessionStart`, `SessionEnd`, `UserPromptSubmit`, `Stop`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PostToolBatch`, `SubagentStart`, `SubagentStop`, `TaskCreated`, `TaskCompleted`, `InstructionsLoaded`, `CwdChanged`, `FileChanged`, and others."
- url: https://docs.anthropic.com/en/docs/claude-code/hooks
- source_type: primary
- published: unknown
- confidence: high

### [7] Claude Code hooks support HTTP endpoints, LLM prompts, and agent-based hooks as handler types
- quote: "Hook handlers can be: command (shell script), HTTP endpoint, LLM prompt, or agent (multi-turn subagent). Agent hooks are experimental."
- url: https://docs.anthropic.com/en/docs/claude-code/hooks
- source_type: primary
- published: unknown
- confidence: high

### [8] Claude Code exports OpenTelemetry traces, metrics, and log events
- quote: "The Agent SDK exports: metrics (counters for tokens, cost, sessions, lines of code, tool decisions), log events (structured records for each prompt, API request, API error, tool result), traces (spans for each interaction, model request, tool call, and hook — beta)."
- url: https://docs.anthropic.com/en/docs/claude-code/agent-sdk/observability
- source_type: primary
- published: unknown
- confidence: high

### [9] Claude Code `Channels` feature pushes events into running sessions via MCP
- quote: "A channel is an MCP server that pushes events into your running Claude Code session, so Claude can react to things that happen while you're not at the terminal."
- url: https://docs.anthropic.com/en/docs/claude-code/channels
- source_type: primary
- published: unknown
- confidence: high

### [10] Claude Code `AgentView` provides real-time UI monitoring of multiple session states
- quote: "Agent view shows what every session is doing and which ones need your input. Each row shows the session's name, current activity, and its age. Row summaries are generated by a Haiku-class model showing what the session is working on."
- url: https://docs.anthropic.com/en/docs/claude-code/agent-view
- source_type: primary
- published: unknown
- confidence: high

### [11] Claude Code hooks can inject additionalContext to modify tool results seen by the model
- quote: "Return `additionalContext` to append information to the tool result. To replace the tool's output before Claude sees it, set `updatedToolOutput`."
- url: https://docs.anthropic.com/en/docs/claude-code/agent-sdk/hooks
- source_type: primary
- published: unknown
- confidence: high

## Dead ends
- MiMoCode docs site (mimo.xiaomi.com) has no hooks, events, or observability API documentation — no equivalent to Claude Code's hooks reference
- No public academic papers found on "live context injection" or "live memory injection" in AI coding agent harnesses (Google Scholar returned no results for those terms as of 2026-08-06)
- MiMoCode schema (https://mimo.xiaomi.com/mimocode/config.json) exposes permission config, snapshot, watcher, but no hooks or telemetry fields
- docs.mimocode.ai DNS resolution failed; no accessible documentation at that domain
