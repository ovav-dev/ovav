# F8: Claude Code hooks deep capability

## Findings

### [1] PostToolUse and PostToolBatch are the primary passive memory observation hooks
- quote: "PostToolUse: After a tool call succeeds. PostToolBatch: After a full batch of parallel tool calls resolves, before the next model call."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [2] MessageDisplay fires while assistant text streams — enables real-time response observation
- quote: "MessageDisplay: While assistant message text is displayed."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [3] InstructionsLoaded fires when CLAUDE.md or rules load into context — passive injection point
- quote: "InstructionsLoaded: When a CLAUDE.md or .claude/rules/*.md file is loaded into context. Fires at session start and when files are lazily loaded during a session."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [4] async:true on command hooks runs them in background without blocking the agent
- quote: "By default, hooks block Claude's execution until they complete. For long-running tasks like deployments, test suites, or external API calls, set 'async': true to run the hook in the background while Claude continues working."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [5] async hooks cannot block or control decisions — the triggering action already completed
- quote: "Async hooks can't block tool calls or return decisions. By the time the hook completes, the triggering action has already proceeded."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [6] async hook additionalContext delivered on next conversation turn; asyncRewake exit code 2 wakes immediately when idle
- quote: "After the background process exits, if the hook produced a JSON response with an additionalContext field, that content is delivered to Claude as context on the next conversation turn."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [7] additionalContext string is wrapped in a system reminder, not visible in chat transcript
- quote: "The additionalContext field passes a string from your hook into Claude's context window. Claude Code wraps the string in a system reminder and inserts it into the conversation at the point where the hook fired. Claude reads the reminder on the next model request, but it doesn't appear as a chat message in the interface."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [8] additionalContext output capped at 10,000 characters per hook; excess written to file with preview
- quote: "Hook output strings, including additionalContext, systemMessage, and plain stdout, are capped at 10,000 characters. Output that exceeds this limit is saved to a file and replaced with a preview and file path."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [9] UserPromptSubmit hook + additionalContext is the most direct injection path at prompt submission
- quote: "UserPromptSubmit: can't replace the prompt; it only injects additionalContext alongside it."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [10] Multiple hooks' additionalContext values concatenate; all delivered to Claude
- quote: "When several hooks return additionalContext for the same event, Claude receives all of the values."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [11] async hooks only supported on type:"command" — prompt and agent hooks cannot be async
- quote: "Only type: 'command' hooks support async. Prompt-based hooks can't run asynchronously."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [12] FileChanged, ConfigChange, CwdChanged, Notification provide infrastructure-level passive observation
- quote: "FileChanged: When a watched file changes on disk. ConfigChange: When a configuration file changes during a session. CwdChanged: When the working directory changes. Notification: When Claude Code sends a notification."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [13] async hook timeout defaults to 10 minutes same as sync hooks
- quote: "If not specified, async hooks use the same 10-minute default as sync hooks."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high

### [14] Subagent tool events fire the same hooks as main session — observation extends to subagent scope
- quote: "Hooks from settings files, managed policy settings, and plugins also run inside subagents. When a subagent calls a tool, tool events such as PreToolUse and PostToolUse fire the same configured hooks as in the main conversation."
- url: https://code.claude.com/docs/en/hooks.md
- source_type: primary
- published: 2026-08-06
- confidence: high
