# F5: Deprecated or removed APIs in WezTerm 2025-2026

## Findings

### [1] `show_update_window` config option is deprecated and inert in nightly builds
The `show_update_window` config option "no longer has any effect and will be removed in a future release." The associated update-notification UI was dropped because the project moved to a nightly-only release model with no formal versioned releases.
- quote: "This option no longer has any effect and will be removed in a future release."
- url: https://wezterm.org/config/lua/config/show_update_window.html
- source_type: primary
- published: unknown (nightly builds only, post-20240203)
- confidence: high

### [2] `font_antialias` is deprecated since March 2021 (version 20210314-114017-04b7cedd)
The option is fully inert: "no longer does anything and will be removed in a future release." The replacement is `freetype_load_target`. Note: this deprecation predates the 2025-2026 window but is listed in the live docs as still present but non-functional.
- quote: "Deprecated starting in version 20210314-114017-04b7cedd; this option no longer does anything and will be removed in a future release. Use freetype_load_target instead"
- url: https://wezterm.org/config/lua/config/font_antialias.html
- source_type: primary
- published: 2021-03-14 (deprecation announced); option still inert in current nightly
- confidence: high

### [3] `font_hinting` is deprecated since March 2021 (same version as `font_antialias`)
Identical situation to `font_antialias`: fully deprecated, no-op, replacement is `freetype_load_target`.
- quote: "Deprecated starting in version 20210314-114017-04b7cedd; this option no longer does anything and will be removed in a future release. Use freetype_load_target instead"
- url: https://wezterm.org/config/lua/config/font_hinting.html
- source_type: primary
- published: 2021-03-14
- confidence: high

### [4] `update-right-status` window event is deprecated since November 2022 in favor of `update-status`
The more general `update-status` event handles both left and right status bars. The `update-right-status` event is "considered to be deprecated in favor of update-status."
- quote: "update-status is a more general event for updating left or right status. update-right-status is considered to be deprecated in favor of update-status."
- url: https://wezterm.org/changelog.html#20221119-145034-49b9839f
- source_type: primary
- published: 2022-11-19
- confidence: high

### [5] `Copy`, `Paste`, `PastePrimarySelection` key assignment actions removed in July 2023
These three old actions were removed; users must migrate to `CopyTo` and `PasteFrom`.
- quote: "Removed deprecated Copy, Paste and PastePrimarySelection actions. Use CopyTo and PasteFrom instead."
- url: https://wezterm.org/changelog.html#20230712-072601-f4abf8fd
- source_type: primary
- published: 2023-07-12
- confidence: high

### [6] `send_composed_key_when_alt_is_pressed` config option removed
This option was removed and behavior folded into the more granular `send_composed_key_when_left_alt_is_pressed` and `send_composed_key_when_right_alt_is_pressed` options.
- quote: "Removed the send_composed_key_when_alt_is_pressed option. When processing generic ALT (eg: that has neither left nor right), if either send_composed_key_when_left_alt_is_pressed or send_composed_key_when_right_alt_is_pressed is true, then the composed form of the key event will be generated."
- url: https://wezterm.org/changelog.html
- source_type: primary
- published: unknown (pre-Feb 2024)
- confidence: high

### [7] Default `ALT-[NUMBER]` key assignments removed since they break non-US keyboard layouts
The default bindings for ALT+number keys were removed because they produced incorrect output for non-US keyboard layouts.
- quote: "Removed the ALT-[NUMBER] default key assignments as they are not good for non-US layouts. #1542"
- url: https://wezterm.org/changelog.html
- source_type: primary
- published: unknown (pre-Feb 2024)
- confidence: high

### [8] Last Resort fallback font removed
The "Last Resort" font fallback mechanism was removed from the font fallback chain.
- quote: "Removed Last Resort fallback font"
- url: https://wezterm.org/changelog.html
- source_type: primary
- published: unknown (pre-Feb 2024)
- confidence: high

### [9] Old basic CPU renderer removed
The legacy CPU-based renderer (not GPU/WebGPU) was fully removed from the codebase.
- quote: "The old basic CPU renderer has been removed."
- url: https://wezterm.org/changelog.html
- source_type: primary
- published: unknown (pre-Feb 2024)
- confidence: high

### [10] Windows: WinPty support removed
Windows dropped support for WinPty, which had been problematic to obtain and configure. All Windowspty usage was replaced by ConPTY.
- quote: "Windows: removed support for WinPty, which was too difficult to obtain, configure and use."
- url: https://wezterm.org/changelog.html
- source_type: primary
- published: 2020-02-02 (per entry 20200202-181957-765184e5)
- confidence: high

### [11] DECRQCRA (checksum rectangular area) disabled by default in nightly — security hardening
DECRQCRA was disabled by default "to prevent silent screen scraping." Users who need it must explicitly set `enable_checksum_rectangular_area = true`. This is a behavioral default change rather than an API deprecation, but it represents a significant configuration change in nightly.
- quote: "DECRQCRA is now disabled by default to prevent silent screen scraping. Set enable_checksum_rectangular_area = true to re-enable it."
- url: https://wezterm.org/changelog.html (Continuous/Nightly section)
- source_type: primary
- published: unknown (in current nightly, post-Feb 2024)
- confidence: high

### [12] WezTerm moved to nightly-only release model — last stable release was Feb 3, 2024
The last tagged stable release is `20240203-110809-5046fc22` (Feb 3, 2024). All subsequent development appears only in nightly builds. This means there are no versioned changelog entries for 2025 or 2026 — only the undated "Continuous/Nightly" section at the top of the changelog covers post-Feb 2024 changes.
- quote: "This commit was signed with the committer's verified signature." / "See https://wezfurlong.org/wezterm/changelog.html#20240203-110809-5046fc22 for the changelog"
- url: https://github.com/wezterm/wezterm/releases/tag/20240203-110809-5046fc22
- source_type: primary
- published: 2024-02-03
- confidence: high
