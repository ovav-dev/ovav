# F1: WebGPU front_end availability in WezTerm nightly 2026 builds

## Findings

### [1] `front_end = "WebGpu"` is a valid and documented config option
The `front_end` config option accepts three values: `"OpenGL"`, `"Software"`, and `"WebGpu"`. The WebGPU front_end uses GPU acceleration via platform-specific backends: Metal (macOS), Vulkan (Linux), and DirectX 12 (Windows).
- quote: "The WebGpu front end allows wezterm to use GPU acceleration provided by a number of platform-specific backends: Metal (on macOS), Vulkan, DirectX 12 (on Windows)"
- url: https://wezterm.org/config/lua/config/front_end.html
- source_type: primary
- published: unknown (doc page, not dated)
- confidence: high

### [2] WebGPU front_end was introduced in Nov 2022 (version 20221119-145034-49b9839f)
The `front_end = "WebGpu"` option was first made available starting from commit/version tag 20221119-145034-49b9839f.
- quote: "Since: Version 20221119-145034-49b9839f — The functionality described in this section requires version 20221119-145034-49b9839f of wezterm, or a more recent version."
- url: https://wezterm.org/config/lua/config/front_end.html
- source_type: primary
- published: November 2022 (based on version tag format YYYYMMDD-HHMMSS-commithash)
- confidence: high

### [3] The default front_end was temporarily changed to "WebGpu" in late January 2024, then reverted to "OpenGL" the next day
The docs state: default was `"WebGpu"` in version 20240127-113634-bbcac864 (Jan 27, 2024), then reverted to `"OpenGL"` in version 20240128-202157-1e552d76 (Jan 28, 2024).
- quote: "Since: Version 20240127-113634-bbcac864 — The default is 'WebGpu'. In earlier versions it was 'OpenGL'." Then: "Since: Version 20240128-202157-1e552d76 — The default has been reverted to 'OpenGL'."
- url: https://wezterm.org/config/lua/config/front_end.html
- source_type: primary
- published: January 27-28, 2024 (version tags)
- confidence: high

### [4] Current (post-revert) default front_end is "OpenGL", not "WebGpu"
Since version 20240128-202157-1e552d76 (Jan 28, 2024), the default front_end is `"OpenGL"`. The wezterm.org docs reflect this as the current default. The latest stable release tag is 20240203-110809-5046fc22 (Feb 3, 2024).
- quote: "The default has been reverted to 'OpenGL'. You may wish (or need!) to select `Software` if there are issues with your GPU/OpenGL drivers."
- url: https://wezterm.org/config/lua/config/front_end.html
- source_type: primary
- published: January 28, 2024
- confidence: high

### [5] WebGPU is NOT enabled by default in current WezTerm builds
To use WebGPU, users must explicitly set `front_end = "WebGpu"` in their Lua config. It must be manually selected; it is not the default.
- quote: "The default is 'WebGpu'. In earlier versions it was 'OpenGL'" followed by the revert note confirming the current default is 'OpenGL'.
- url: https://wezterm.org/config/lua/config/front_end.html
- source_type: primary
- published: January 28, 2024
- confidence: high

### [6] Three WebGPU-related config options exist: webgpu_power_preference, webgpu_force_fallback_adapter, webgpu_preferred_adapter
`webgpu_power_preference` defaults to "LowPower" (favoring integrated GPU). `webgpu_force_fallback_adapter` defaults to false. `webgpu_preferred_adapter` allows manual GPU selection. All are only applicable when `front_end = "WebGpu"`.
- quote: "webgpu_power_preference = 'LowPower'" and "webgpu_force_fallback_adapter = false"
- url: https://wezterm.org/config/lua/config/webgpu_power_preference.html, https://wezterm.org/config/lua/config/webgpu_force_fallback_adapter.html
- source_type: primary
- published: November 2022 (all since: 20221119-145034-49b9839f)
- confidence: high

### [7] WezTerm nightly builds are available but the published docs do not reflect post-Feb-2024 changes
The latest stable release on GitHub is 20240203 (Feb 3, 2024). Nightly builds exist at https://github.com/wezterm/wezterm/releases/download/nightly/. The wezterm.org changelog's latest entry is 20240203. The wezterm.org docs (which are the canonical reference) are consistent with version 20240203 and show no evidence of a post-Feb-2024 stable release.
- quote: "See https://wezfurlong.org/wezterm/changelog.html#20240203-110809-5046fc22 for the changelog" (from GitHub releases page)
- url: https://github.com/wezterm/wezterm/releases/tag/20240203-110809-5046fc22
- source_type: primary
- published: February 3, 2024
- confidence: high

### [8] WezTerm has automatic fallback to Software rendering on Windows Remote Desktop
The docs note that WezTerm automatically selects `Software` front_end when started in a Remote Desktop environment on Windows.
- quote: "WezTerm will automatically select `Software` if it detects that it is being started in a Remote Desktop environment on Windows."
- url: https://wezterm.org/config/lua/config/front_end.html
- source_type: primary
- published: unknown
- confidence: high
