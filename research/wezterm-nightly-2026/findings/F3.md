# F3: fancy_tab_bar rendering changes in recent WezTerm nightlies

## Findings

### [1] macOS crash in fancy_tab_bar rendering with INTEGRATED_BUTTONS (Oct 2024)
A crash was reported on macOS 15.1 when launching WezTerm with `window_decorations = "INTEGRATED_BUTTONS|RESIZE"`. The panic occurs in `wezterm_gui::termwindow::render::fancy_tab_bar::build_fancy_tab_bar` at line 423 of `fancy_tab_bar.rs`, caused by a Rust unsafe precondition violation in `slice::from_raw_parts` (null/unaligned pointer) when rendering the fancy tab bar with Harfbuzz font shaping.
- quote: "panic at core/src/panicking.rs:221:5 - unsafe precondition(s) violated: slice::from_raw_parts requires the pointer to be aligned and non-null"
- url: https://github.com/wezterm/wezterm/issues/6336
- source_type: primary
- published: Oct 30, 2024
- confidence: high

### [2] Transparent fancy tab bar backgrounds via window_frame alpha channel (Jan 2024)
WezTerm version 20240127-113634-bbcac864 enabled transparent fancy tab bar backgrounds by allowing `window_frame` colors to specify alpha channel values.
- quote: "Allow window_frame colors now allow specifying the alpha channel value, which enables transparent fancy tab bar backgrounds"
- url: https://wezterm.org/changelog.html#20240127-113634-bbcac864
- source_type: primary
- published: Jan 27, 2024
- confidence: high

### [3] Retro tab bar indentation fix on macOS with INTEGRATED_BUTTONS (Jan 2024)
Version 20240127-113634-bbcac864 fixed an issue where the retro tab bar was indented too far on macOS when using integrated titlebar buttons.
- quote: "retro tab bar indented too far on macOS when using integrated titlebar buttons"

### [9] use_fancy_tab_bar introduced (Jan 2022)
The `use_fancy_tab_bar` config option was introduced in version 20220101-133340-7edc5b5a. When `true` (the default), the tab bar is rendered in a native style with proportional fonts. When `false`, the tab bar uses a retro aesthetic with the main terminal font.
- quote: "When set to true (the default), the tab bar is rendered in a native style with proportional fonts. When set to false, the tab bar is rendered using a retro aesthetic using the main terminal font."
- url: https://wezterm.org/config/lua/config/use_fancy_tab_bar.html
- source_type: primary
- published: Jan 1, 2022
- confidence: high

### [10] Retro tab bar with INTEGRATED_BUTTONS window decoration (Apr 2023)
Version 20230408-112425-69ae8472 introduced retro tab bar support with integrated window management buttons (hide, maximize, close) when using `window_decorations = "INTEGRATED_BUTTONS|RESIZE"`.
- quote: "When using window_decorations = \"INTEGRATED_BUTTONS|RESIZE\", you can control how the different buttons are drawn for the retro tab bar"
- url: https://wezterm.org/config/lua/config/tab_bar_style.html
- source_type: primary
- published: Apr 8, 2023
- confidence: high

### [11] tab_bar_style API changes removed old elements (Aug 2021)
Version 20210814-124438-54e29167 removed `new_tab_left`, `new_tab_right`, `new_tab_hover_left`, `new_tab_hover_right` and replaced them with the more flexible `new_tab` and `new_tab_hover` elements. Earlier in 20210502-154244-3f7122cb, `active_tab_left`, `active_tab_right`, `inactive_tab_left`, `inactive_tab_right`, `inactive_tab_hover_left`, `inactive_tab_hover_right` were removed and replaced by the `format-tab-title` event.
- quote: "new_tab_left, new_tab_right, new_tab_hover_left, new_tab_hover_right have been removed and replaced by the more flexible new_tab and new_tab_hover elements"
- url: https://wezterm.org/config/lua/config/tab_bar_style.html
- source_type: primary
- published: Aug 14, 2021
- confidence: high
