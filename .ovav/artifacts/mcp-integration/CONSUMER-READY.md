## 🚀 Consumer Journey

### 1. Install (1 command)
```bash
npx ovav-mcp-setup
# OR
git clone https://github.com/ovav/ovav-consumer.git && ./install.sh
```

### 2. Configure (auto-detected)
```bash
# Editor configs auto-generated
# Just set your tokens:
export FIGMA_TOKEN="your_token"
export DATABASE_URL="postgresql://..."
```

### 3. Use (natural language)
```
User: "Generate a login form from this Figma design"
→ Agent uses figma-workflow skill
→ Returns: Login.tsx with proper styling

User: "Show me active users from last 7 days"
→ Agent uses database-queries skill
→ Returns: User records formatted

User: "Design a REST API for products"
→ Agent uses api-design skill
→ Returns: OpenAPI spec + implementation
```
