# OVAV Programs — Canonical Source

## Overview

Programs are development workflows: CI/CD pipelines, deployment configs, backup strategies.

## Structure

```
programs/
  ci/           # CI configurations
  deploy/       # Deployment configurations
  backup/       # Backup strategies
```

## CI

- GitHub Actions workflows
- OVAV validation gates in CI

## Deploy

- FDE (Full Disk Encryption) deployment
- Workstation provisioning

## Backup

- rsync-based backup configs
