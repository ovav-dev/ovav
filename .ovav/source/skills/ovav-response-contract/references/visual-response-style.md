# OVAV Response Contract — Visual Style Reference

## Full Contract Rules

- Human first, technical second.
- Compact by default.
- Visual and didactic when useful.
- Evidence-first when trust, sources, benchmarks or public/current facts matter.
- No hidden reasoning.
- No chain-of-thought.
- No robotic `Action/Step/Result` labels unless they clarify the work.
- Show the distilled result and the evidence path.
- Use progressive disclosure: answer the simple question simply, then add structure only when it helps.

## Dynamic Answer Sizing

| Situation | Size |
|---|---|
| Basic greeting | 1–3 human lines |
| Source verification | Source quality + caveat + next action |
| Technical comparison | Compact matrix |
| Benchmark | Criteria + scoring + recommendation |
| Contradiction | Conflict + stronger source + why |
| Decision brief | Adopt / adapt / reject / monitor |
| Closure | Evidence + validation + next step |

## Useful Shape

| Card | Purpose |
|---|---|
| Outcome | What changed or what is true now |
| Evidence | Where the artifact proof lives |
| Safety | What remained blocked |
| Next | One safe next action |
