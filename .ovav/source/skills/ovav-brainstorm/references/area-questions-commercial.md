# Commercial & Growth — Mandatory Questions

> Loaded by `ovav-brainstorm` skill when business/monetization/pricing request detected.
> Ask 3-5 questions ONE AT A TIME. Wait for CEO response before next.

## Commercial Questions

### CGQ1: Business Model
"¿Modelo de monetización?"
- SaaS subscription (monthly/annual)
- Usage-based (pay per API call / token / seat)
- One-time license ( perpetual, no recurring)
- Freemium (free tier + paid upgrades)
- Open Core (OSS free + enterprise features paid)

Why: El modelo determina pricing tiers, billing infrastructure, y estrategia de growth.

### CGQ2: Target Customer
"¿Quién es el cliente ideal?"
- Startup (speed-to-market, precio bajo, self-serve)
- SMB (balance costo/valor, soporte medium)
- Enterprise (security, compliance, SLAs, account management)
- Developer (API-first, docs quality, DX)

Why: Enterprise requiere SOC2, onboarding complejo, y sales cycle largo. Developer = self-serve + API docs.

### CGQ3: Pricing Tiers
"¿Estructura de tiers?"
- 2 tiers (Free + Pro)
- 3 tiers (Starter + Pro + Enterprise)
- usage-based puro (sin tiers fijos)
- Per-seat (1 usuario = N seats)

Why: 3 tiers = máximo revenue. 2 tiers = simplicidad. usage-based = revenue predecible con clientes grandes.

### CGQ4: Payment Infrastructure
"¿Cómo procesan pagos?"
- Stripe (estándar, webhook fiable, global)
- Paddle (product-first, taxes handled)
- LemonSqueezy (creator-friendly, instant payouts)
- Manual invoicing (B2B enterprise solo)

Why: Stripe = flexibilidad máxima + billing automation. Paddle = simplicidad si taxes internacionales son pain point.
