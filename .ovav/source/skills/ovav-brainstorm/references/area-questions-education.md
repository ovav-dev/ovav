## Education Questions

### ECQ1: Learning Goal
"¿Cuál es el objetivo de aprendizaje?"
- Get hired (preparar para mercado laboral)
- Skill upgrade (profundizar en area existente)
- Career transition (cambiar de campo)
- Knowledge acquisition (aprender por interés personal)
- Teaching/mentoring (enseñar a otros)

Why: El objetivo determina profundidad técnica vs soft skills y qué certificaciones importan.

### ECQ2: Current Level
"¿Nivel actual en el tema?"
- Beginner (sin experiencia previa)
- Intermediate (1-3 años de experiencia)
- Advanced (3+ años, buscando liderazgo técnico)
- Expert (maestro, el topic es already精通)

Why: Curriculum para beginners necesita foundational concepts. Advanced learners saltan fundamentals.

### ECQ3: Time Commitment
"¿Cuánto tiempo disponible?"
- < 5 horas/semana (aprendizaje lento, constante)
- 5-10 horas/semana (modo intensivo)
- 10+ horas/semana (bootcamp mode)
- Micro-learning (< 1 hora/day con spaced repetition)

Why: Tiempo disponible determina si es viable un bootcamp intensivo o si se requiere curriculum más largo y distribuido.

### ECQ4: Learning Format
"¿Formato preferido?"
- Course-based ( Udemy, Coursera, estructura rigid)
- Project-based ( aprender buildendo cosas reales)
- Reading-heavy (papers, libros técnicos)
- Mentorship (1-on-1 guidance)
- Cohort-based (grupo con deadline común)

Why: Project-based = retention mejor. Course-based = estructura clara. Mentorship = fastest path con el mentor correcto.
