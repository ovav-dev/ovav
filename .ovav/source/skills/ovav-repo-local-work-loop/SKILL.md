# OVAV Repo-Local Work Loop

## Current Purpose

This skill governs the practical OpenCode work loop under current runtime enforcement, context economy, visual delivery and safe-stop rules.

## Loop

1. Service Area Router — resolve service area, visible profile, lead, task class, risk, delegation mode, context mode, validation mode and delivery contract before loading context.
2. Session Capsule — isolate profile/mode; inherit only sanitized handoff, never raw chat, raw tool output, raw repo context or previous role assumptions.
3. Context Gateway — classify source/path before internal reads.
4. Tool Gateway — evaluate area/mode/risk before tools or capabilities.
5. Delegation Router — keep `lead_only`/`skill_only` by default; activate `focused_squad`, `full_squad` or `critical_squad` only by size/risk.
6. Context Economy — choose `T0_none`, `T1_tiny`, `T2_compact`, `T3_focused`, `T4_full_scoped` or `T5_closure_grade` with an escalation reason.
7. Work — execute smallest safe source-local action.
8. Handoff/Trace — sanitize cross-area transfer and produce trace event or trace-ready payload for non-trivial actions.
9. Validate/Close — run task-appropriate validators/harnesses, check drift, stage exact files only and deliver selected visual contract.
10. Safe Stop — if Host Runtime limits interrupt work, emit the Safe Stop Report and separate Host Runtime from OVAV Runtime.
