# Professional Area Parity

## Shared Rules

Both Platform Engineering and Research Intelligence inherit these improvements:

1. **Compact SKILL.md files** — ideally ≤50 lines; details in references/.
2. **Progressive context loading** — greeting/simple uses minimal context; implementation escalates automatically.
3. **Harness Intelligence Router** — selects right harness family by intent, lane, risk and segment.
4. **Spanish user-facing responses** — answers in Spanish; canonical terms in English.
5. **English internal implementation** — routing labels, harness contracts, evidence JSON, comments.
6. **Repo-local safety boundaries** — no global config, no plugins, no Engram, no install, no UI/TUI, no MCP/A2A, no external services.
