# OVAV Compatibility

## Shell

Primary development and testing environment: **fish** shell. Bash and Zsh are also supported.

## Editor

Development optimized for **NVIM** (Neovim). Terminal-based workflows preferred.

## AI Platform

OVAV is built as a governor for **OpenCode**. Model body switching is automatic via the L3 Model Body Router.

## System Requirements

- Python 3.12+
- Git 2.40+
- WSL2 (Windows) or native Linux
- OpenCode CLI client
