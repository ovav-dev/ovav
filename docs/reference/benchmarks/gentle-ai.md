# Benchmark — Gentle AI

Gentle AI is the practical benchmark for ecosystem configuration. It provides memory, SDD, skills, MCP, provider switcher, persona, security-first permissions, per-phase model assignment, backups, Engram and delegation triggers.

## What OVAV absorbs

| Gentle AI capability | OVAV adaptation |
|---|---|
| `/sdd-init` | Auto-triggered `h_sdd_init` from chat interaction. |
| `skill-registry refresh` | Skill Manager discovery + scoring + rule packs. |
| Engram | Memory Gateway + healthcheck + privacy gates. |
| Backups | Authoritative install governor + rollback. |
| Delegation triggers | Lead-or-delegate decision + squad runtime. |
| SDD profiles | Service profiles + phase DAG + model routing. |

## What OVAV improves

- customer-visible service profiles,
- one lead per profile,
- lanes instead of many visible profiles,
- artifact-first execution,
- evidence ledger,
- human response translator,
- commercial install governor.
